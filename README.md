# Neon Client UI Prototype

An original, standalone UI concept for a custom Eaglercraft 26.2 client. This prototype explores a dark neon visual theme, menu navigation, and a few client-side quality-of-life preferences.

## Run locally

Open `index.html` in a browser, or serve this directory with:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Scope

This is a front-end prototype, not a playable client or a gameplay add-on. Its menu actions and preferences are demonstration-only and do not connect to a game. Integration requires a documented add-on interface for a client build you are authorized to modify. This project does not include Eaglercraft or Minecraft source code, assets, or client binaries.
